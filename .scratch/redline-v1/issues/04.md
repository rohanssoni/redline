## What to build

The reader sees **gaps** — terms the agreement does not contain but should (e.g. no late-payment term) — in the same severity-ranked list as flags (ADR-0005).

`analyzeDocument` returns `gaps[]`. A gap has no source sentence, because there is no sentence; it is phrased as a whole-document claim ("this agreement contains no late-payment term") and visibly labelled as a gap, not a flag. Severity governs order; type governs what an item may claim. A high-severity gap can outrank a low-severity flag, but prominence never turns a gap into a flag.

## Acceptance criteria

- [ ] `analyzeDocument` returns `gaps[]`, each with a severity and a whole-document statement
- [ ] Flags and gaps render interleaved in one list ordered by severity
- [ ] A gap is visually distinguishable from a flag and never displays a source sentence
- [ ] Test: a gap never carries a source sentence and never appears in `flags[]`, at any severity, including a fixture where the gap is the highest-severity item
- [ ] Gaps are persisted with the analysis result
