# #20 Keep a no-account analysis by signing up

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

A visitor who tried a document without an account can sign up from the result and keep it. The tab still holds the text and its analysis, so they're saved to the new account's library without calling the model again.

If the visitor leaves the tab before signing up, the document is gone, because nothing was stored. The result says so plainly.

## Acceptance criteria

- [ ] Signing up from a no-account result, in the same tab, saves the document text and its analysis to the new account's library
- [ ] Test: saving on sign-up makes no model call
- [ ] The saved text is exactly the text that was analysed, so every source sentence still verifies against it
- [ ] Once saved, the document behaves like any other document in the library
- [ ] The no-account result tells the visitor that leaving the tab without signing up loses the document
- [ ] Copy has been run through the humanizer skill
