## What to build

`npm run eval` reads every document in the gold set through the same pipeline `npm run smoke` uses, against the real model with the OpenRouter settings in `.env.local`, and reports how well the analysis did against what the gold set says is in each document. It changes no app code, no prompt and no model setting.

The gold set is kept outside the repo, in a folder that holds `corpus/` and `fixtures/` so the relative paths in `manifest.json` still resolve. It is copied, never retyped. Its sentences carry curly quotes, ligatures and non-breaking spaces on purpose.

It reports the three things `PRD.md` "How we measure it" defines:

- **Recall**: planted clauses found, out of planted clauses of the types this product flags. Types it leaves out are listed as out of scope and never counted as misses. A planted clause is found when a flag quotes a sentence that overlaps it. Whether that flag named the right type is reported separately, through a mapping from this product's free-text clause types onto the gold set's seven.
- **Groundedness**: flags whose quoted sentence appears in the document character for character, out of all flags the model returned.
- **Clean documents**: flags shown on the documents that should come back clean.

A model wrote the gold set, so every figure is an upper bound and never a promise to a reader.

Every decision made building it, and why, is in `eval/README.md`.

## Acceptance criteria

- [ ] `npm run eval` runs every document in `manifest.json` through `analyzeDocument` with `createOpenRouterClient()`, the same way `npm run smoke` does
- [ ] No app code, prompt or model setting changes
- [ ] The clause type mapping and the out-of-scope types are written into `eval/README.md` with their reasons
- [ ] A document whose model call fails is left out of every denominator, and the run says how many were left out. A failed call is never a miss
- [ ] Recall is split by whether the planted sentence contains a curly quote or apostrophe, a non-breaking space, an fi or fl ligature, an em dash, or two spaces in a row
- [ ] Every rate is printed as count/count and as a percentage
- [ ] Each run is saved to `eval-runs/` as a `.txt` and a `.json` named for its start time, and the JSON holds every flag with its document, clause type, severity, quoted sentence, and whether it matched a planted clause
- [ ] Test, no network: every gold-set sentence appears exactly once in its document
- [ ] `PRD.md` has a "How we measure it" section
