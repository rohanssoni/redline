# #8 Soft counter-offer for every flag

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

Every flag shows a drafted **counter-offer** — replacement language for that one clause — in the **soft** stance, ready to send back (ADR-0009).

`draftCounterOffer(flag, stance)` with `stance: 'soft'` is called once per flag at analysis time. A counter-offer rewrites only the flagged clause, never the whole agreement, and never argues against terms the document doesn't contain — it inherits ADR-0001's grounding. Gaps never get a counter-offer, under any circumstance (ADR-0014).

The reader can copy a counter-offer. (Copy is also the "sent" signal a later ticket tracks.)

## Acceptance criteria

- [ ] Each flag in the list shows its soft counter-offer
- [ ] `draftCounterOffer` is called exactly once per flag at analysis time, with `'soft'`
- [ ] `draftCounterOffer` is never called for a gap; no gap displays counter-offer language
- [ ] A counter-offer addresses only its own flagged clause
- [ ] The reader can copy a counter-offer to the clipboard
- [ ] Soft counter-offers are persisted with the analysis result
- [ ] Tests cover: one soft draft per flag, none per gap
