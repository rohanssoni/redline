# #16 Track counter-offers sent, by stance

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

The product owner can see how often counter-offers are sent — the primary success metric — split by stance (soft vs. firm) (PRD success metrics, ADR-0009).

**Decision made while breaking down #1:** "sent" is measured as the reader copying a counter-offer. The app can't observe a message actually leaving, so copy is the proxy. Record it as a copy event and label it that way in reporting so the proxy isn't mistaken for confirmed sends.

## Acceptance criteria

- [ ] Copying a counter-offer records a sent event with the flag, the stance copied, and the document
- [ ] The product owner can view counter-offers sent, split by soft and firm
- [ ] Reporting labels the metric as copy-based
- [ ] Repeated copies of the same counter-offer in the same stance are distinguishable from distinct sends (count unique flag+stance as well as raw copies)
