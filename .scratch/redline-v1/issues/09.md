# #9 Switch a flag's counter-offer to firm, on demand

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

The reader can switch a single flag's counter-offer from soft to **firm** and get a redraft for that flag only — using leverage exactly where they know they have it (ADR-0009).

The firm version is generated on demand the moment the reader switches, never pre-generated (ADR-0012). Switching shows a loading state. Once generated, the firm version is cached and not regenerated on later views or on switching back and forth. Stance is per flag; switching one flag never changes another.

## Acceptance criteria

- [ ] Each flag has a soft/firm stance control, defaulting to soft
- [ ] Switching to firm calls `draftCounterOffer(flag, 'firm')` for that flag only, with a visible loading state
- [ ] Test: immediately after `analyzeDocument`, only the soft counter-offer exists for a flag; the firm one is absent until `draftCounterOffer(flag, 'firm')` is called
- [ ] A generated firm version is persisted and reused — switching back to firm or reopening the document does not call the model again
- [ ] Switching one flag's stance leaves every other flag's stance unchanged
- [ ] Generation failure leaves the soft counter-offer intact and tells the reader
