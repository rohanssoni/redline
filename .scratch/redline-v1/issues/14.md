# #14 Saved library of past documents

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

A signed-in reader can browse a saved library of their past documents and reopen any of them to see its stored analysis — without re-uploading and without a new model call.

Only extracted text plus the document's most recent analysis result is stored — never the original file (`CLAUDE.md`, settled).

This ticket depends only on the skeleton so it can start early; it shows whatever the stored analysis contains. Tickets that add to the analysis (flags, gaps, counter-offers, stances) are responsible for persisting their own output so the library shows it.

## Acceptance criteria

- [ ] A library view lists the reader's past documents, most recent first, with enough to identify each (name, date)
- [ ] Opening a document shows its stored analysis without calling the model
- [ ] A reader only sees their own documents
- [ ] A reader can delete a document from their library
- [ ] No original file exists in storage — only extracted text and analysis results
