## What to build

When a document produces no flags or gaps above the severity threshold, the reader sees a dedicated **clean read** — "this reads as a normal agreement" — rather than an empty list (ADR-0008). It is a first-class outcome, so a lack of flags reads as good news, not as the tool failing.

The copy communicates confidence without hedging; it does not say "we didn't find anything, but check yourself anyway". It makes no claim beyond what the analysis supports.

## Acceptance criteria

- [ ] `analyzeDocument` returns an explicit clean-read result when nothing clears the severity threshold, distinguishable from a failed or incomplete analysis
- [ ] The UI renders a dedicated clean-read view, never a bare empty list
- [ ] A failed analysis never renders as a clean read
- [ ] The plain-English summary still shows on a clean read
- [ ] Test: a fixture of a normal agreement returns the clean-read result
