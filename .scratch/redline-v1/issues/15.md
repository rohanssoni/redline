# #15 Dismiss a flag, with dismissal rate tracked

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

A reader can dismiss a flag they've read and decided isn't a problem for them. The product owner can see the flag dismissal rate, with **red-line-triggered flags tracked separately** from ordinary flags (PRD success metrics, ADR-0006, ADR-0013).

A nonzero dismissal rate is expected by design — it's the cost of favoring recall. The metric exists to tell whether the confidence threshold or red-line matching needs retuning; a reader dismissing their own red line is a different signal from dismissing a borderline flag.

## Acceptance criteria

- [ ] Each flag has a dismiss action; a dismissed flag is visually set aside but still recoverable, and the dismissal persists
- [ ] Dismissals are recorded with whether the flag was red-line-triggered
- [ ] The product owner can view the dismissal rate for ordinary flags and for red-line-triggered flags separately
- [ ] Gaps are not part of this metric
