## What to build

A visitor who takes the landing page's action can try one document without an account. They get the plain-English summary and the severity-ranked flags and gaps, with every flag's source sentence, or the clean read when nothing clears the threshold.

Counter-offers, the question box, red lines, and the library need an account. An anonymous analysis runs with no red lines.

The document's text stays in the browser tab. It is sent with the analysis request and verified within that request, but never written to the database.

Anonymous analyses cost real model calls and the product has no payments, so they are limited per IP per day, and documents have a maximum length. Both are enforced server-side with Supabase and need no new service or dependency. The exact limits aren't decided yet: record the chosen values on this issue before merge.

## Acceptance criteria

- [ ] The landing page's action opens a no-account upload that needs no sign-in
- [ ] The result shows the summary, ranked flags and gaps, and each flag's source sentence, or the clean read
- [ ] Every flag passes the verbatim source-sentence check against the text sent in that request
- [ ] Test: an anonymous analysis writes no document text and no analysis result to the database
- [ ] Test: a request over the per-IP daily limit is refused with a plain explanation, before any model call
- [ ] Test: a document over the maximum length is refused with a plain explanation, before any model call
- [ ] Signed-in readers are not subject to the anonymous limit
- [ ] No counter-offers, question box, red lines, or library are available without an account, and the result says plainly what an account adds
- [ ] The chosen daily limit and maximum length are recorded on this issue
- [ ] Copy has been run through the humanizer skill
