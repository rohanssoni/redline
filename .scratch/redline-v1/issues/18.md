# #18 Paste an agreement's text instead of uploading

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

A signed-in reader can paste an agreement's text instead of uploading a file (ADR-0020). Upload stays the recommended path and the one the input step leads with.

Pasted text becomes the stored document text, so it is exactly what every source sentence is verified against (ADR-0001). A paste can break lines or reorder columns, so the input step says plainly that upload gives the most faithful source sentences. A pasted image is refused, since reading it would need OCR, which is excluded.

## Acceptance criteria

- [ ] The input step leads with upload and offers paste as the alternative
- [ ] Pasted text is stored as the document text, and the original clipboard content is never stored in any other form
- [ ] Test: flags on a pasted fixture pass the same verbatim source-sentence check as flags on an uploaded one
- [ ] Both paths produce the same stored-text shape; `analyzeDocument` does not know which path was used
- [ ] The input step tells the reader that upload gives the most faithful source sentences
- [ ] Pasting an image is refused with a plain explanation, and nothing is analysed
- [ ] Copy on the input step has been run through the humanizer skill
