# #12 LLM judge on red-line matches, disagreement logged

Labels: ready-for-agent

## Parent

#1 — Redline v1: full-scope spec

## What to build

Every semantic red-line match is reviewed by a second, independent model call — an LLM-as-judge — that decides whether the match reasonably fits the red line's intent (ADR-0018).

When the judge disagrees, the disagreement is **logged for later audit only** (ADR-0019). The flag renders exactly as it would otherwise: not suppressed, not marked down, no confidence marker. A red line is never silently dropped (ADR-0013), and match-quality doubt is not the kind of uncertainty a flag may show (ADR-0010).

The judge's output is a review-priority signal, not proof of correctness. A human-labeled test set is out of scope.

## Acceptance criteria

- [ ] Each red-line-triggered flag gets one independent judge call
- [ ] Disagreements are written to a judge-disagreement log with the red line, source sentence, and judge reasoning
- [ ] Judge agreement rate/disagreement rate is queryable for audit
- [ ] Test: when the fake judge disagrees, the flag is still present in the output and identical to the agree case
- [ ] Nothing in the reader-facing UI reflects the judge's verdict
- [ ] A judge call failure does not block or alter the flag
