## What to build
A clause that violates one of the reader's **red lines** always shows up as a
flag — even when the plausibility filter (ADR-0004) or the confidence threshold
(ADR-0006) would otherwise drop it.

Matching is **semantic, not literal** (ADR-0015): a clause triggers the override
when the model judges it violates the red line's intent, even when it is phrased
nothing like how the reader wrote it. A client's contract rarely echoes a reader's
own words, so literal overlap would make the override almost never fire.

**The override applies to filtering only, never to the source-sentence check.**
A red-line match whose quoted sentence is not found verbatim in the document
still does not render. ADR-0001 has no exception, and this is the one place
someone would be tempted to carve one.

Each red-line-triggered flag is **marked internally as such, recording which red
line it matched**, so #12's judge and #15's dismissal metric can tell it apart.
The reader sees it as an ordinary flag with its source sentence — no badge, no
confidence marker, nothing that would stretch ADR-0010's hedging bound.

Red-line-triggered flags get soft counter-offers like any other flag.

## The fixture is built for this
`tests/fixtures/adhesion-agreement.json`:
- The flag `no-portfolio-use` has `plausible: false` — it is the clause the
  plausibility filter drops when no red line is supplied.
- `decoys.redLineOnly.redLine` is the reader's red line, in the reader's own
  words, phrased nothing like the clause. That is the semantic-matching case.
- `redLines[1]` is a red line this document does **not** violate, so you can
  assert the override does not fire spuriously.

## Tests
- A red-line match produces a flag against a fixture engineered to otherwise fail
  the **plausibility filter**.
- A red-line match produces a flag against a fixture engineered to otherwise fall
  **below the confidence threshold**.
- A red-line match whose source sentence is **not** in the document text does not
  appear in the output. This one is the important one.
- A clause phrased differently from the red line but violating its intent triggers
  the override (the semantic case, not a string match).
- A red line the document does not violate produces no flag.
- Red-line-triggered flags carry a soft counter-offer like any other flag.
